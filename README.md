Este repositório reúne as atividades desenvolvidas durante a disciplina de Desenvolvimento Front-End, contemplando exercícios práticos e a construção de uma aplicação completa voltada para o gerenciamento de pacientes de uma clínica de nutrição.

## 📁 Estrutura do Repositório

### 📚 Exercícios e Atividades

Conjunto de práticas desenvolvidas durante as aulas para consolidação dos conteúdos abordados, incluindo:

* Estruturação semântica com HTML5;
* Estilização avançada utilizando CSS3;
* Manipulação de elementos da página através do JavaScript;
* Eventos e interatividade;
* Organização e boas práticas de desenvolvimento Front-End.

### 🥗 Sistema de Nutrição

Projeto principal da APS, responsável pelo gerenciamento de pacientes e cálculo automático de indicadores corporais.

---

## ⚙️ Principais Recursos

### 📊 Cálculo Automático de IMC

Processamento automático das informações cadastradas para obtenção do Índice de Massa Corporal dos pacientes.

### ✅ Validação Inteligente de Dados

Verificação dos campos obrigatórios antes da inclusão de novos registros, evitando informações inconsistentes no sistema.

### 🚨 Exibição de Erros em Tempo Real

Identificação simultânea de múltiplos erros de preenchimento, proporcionando maior clareza ao usuário durante o cadastro.

### 🎨 Destaque Visual de Inconsistências

Utilização de classes CSS para sinalizar visualmente informações inválidas na interface.

### 🔄 Atualização Dinâmica da Tabela

Inclusão de novos pacientes sem necessidade de recarregar a página, utilizando manipulação direta do DOM.

### 🧹 Limpeza Automática do Formulário

Após um cadastro válido, os campos são redefinidos automaticamente para uma nova inserção.
